# Midnight Lace Frontend

Frontend de Midnight Lace, una app movil de subastas con catalogos, pujas en vivo, pagos y carga de articulos para remate.

## Tecnologias

- React Native
- Expo

## Comandos

```bash
npm install
npm start
```

Para abrir la app en Android:

```bash
npm run android
```
